# Google Terminal Search

> Run Google searches directly from your terminal.

![Status](https://img.shields.io/badge/status-active-success)
![Stack](https://img.shields.io/badge/stack-Bash-informational)
![License](https://img.shields.io/badge/license-MIT-blue)

## Overview

CLI that runs Google searches and returns parseable results — open URLs, pipe output into other tools, or use it as a quick lookup from the shell.

## Tech Stack

- **Bash**

## Features

- Parseable output
- Pipe-friendly
- Zero dependencies

## Getting Started

```bash
# Clone the repository
git clone https://github.com/fernandofatech/google-terminal-search.git
cd google-terminal-search

# No build step — run the script directly
chmod +x *.sh
./main.sh
```
